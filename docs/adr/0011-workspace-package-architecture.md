# Split the fork into core, history, Repo Session, CLI, and Web workspace packages

We decided to restructure the fork as a pnpm workspace with separate packages for the reusable semantic core, the history layer, the Repo Session runtime, the CLI, and the Web app. `packages/core` owns decoding, parsing, semantic snapshots, and semantic diffing without DOM, Git, or SQLite dependencies; `packages/history` owns the Save History Repository, watcher lease, Git adapter, and SQLite Semantic Read Model; `packages/repo-session` owns file-event scheduling, local HTTP, and the browser-safe HTTP wire contract above History; `apps/cli` owns command parsing and terminal output; `apps/web` owns the Vite Web UI in static and local history modes. ADR-0020 later made Repo Session HTTP mandatory while leaving this package boundary unchanged.

This keeps the semantic core as the main deep Module used by both the CLI and Web UI, keeps persistence in History, and keeps filesystem watching and local HTTP behavior out of the static browser build. Repo Session depends on History, which depends on Core; no application owns a reverse dependency.
